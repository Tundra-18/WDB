CSS Height and Width Examples

1. Length (Fixed) vs Percentage (%)

Fixed Dimensions (width: 300px; height: 150px;)

Percentage Dimensions (width: 50%; height: 100px;)
Takes 50% width of its parent container.

2. Min/Max Dimensions

min-width: 200px; max-width: 500px;
min-height: 100px; max-height: 200px;
This box will scale with content but stay within these limits.

3. Width vs Max-Width (Try resizing your browser window)

Problem: Fixed width (600px) - Will overflow on small screens causing horizontal scroll.

width: 600px;

Solution: Responsive max-width (600px) - Will automatically shrink on small screens.

max-width: 600px;

4. Best Practice Responsive Container

width: 100%; max-width: 900px;
Full width on mobile screens, caps at 900px on desktop screens.
