Background Shorthand & Attachment

Instead of writing multiple CSS properties separately, we can use the background shorthand property to define the background color, image, repeat behavior, attachment, position, and size in a single line: 

            background: #f4f4f4 url("img_tree.png") 
                no-repeat fixed right top / cover;

In this example, the background attachment is set to fixed, which means the background image remains in the same position on the screen while the page content scrolls. Try scrolling down the page—you will notice that the text moves, but the background image stays pinned to the top-right corner of the browser window.
