CSS Background Properties

1. Background Repeat

The background-repeat property sets if/how a background image will be repeated.

  • repeat-x: Repeats the image horizontally.
  • repeat-y: Repeats the image vertically.
  • no-repeat: Shows the background image only once.

2. Background Position

The background-position property is used to set the starting position of the background image.
