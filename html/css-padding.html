CSS Padding Examples

1. Individual Sides Padding

Padding-Top: 40px, Right: 20px, Bottom: 10px, Left: 50px

2. Shorthand Padding (Clockwise: Top Right Bottom Left)

padding: 25px 50px 75px 100px;

3. Box Sizing Comparison (Both have Width: 300px, Padding: 25px)

box-sizing: content-box; (Default)
Total Width becomes 350px (300px + 25px + 25px). This breaks the layout.

box-sizing: border-box; (Recommended)
Total Width stays exactly 300px. Content shrinks to fit inside.
